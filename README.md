# India Oil, Rupee & Inflation Impact Analysis

## Project Overview
This project analyzes the relationship between crude oil prices, the Indian rupee (USD/INR), inflation indicators, and the Indian stock market. The goal is to understand how changes in global oil prices may relate to India's economic indicators and market movements.

## Objectives
- Analyze crude oil price trends.
- Study changes in the USD/INR exchange rate.
- Explore CPI and WPI inflation trends.
- Examine NIFTY 50 and SENSEX market movements.
- Investigate relationships between oil price spikes, currency changes, and stock market performance.

## Tools & Technologies
- **Database:** PostgreSQL
- **Query Language:** SQL (PostgreSQL)
- **Visualization:** Microsoft Power BI
- **Data Format:** CSV

## Project Structure
- **PostgreSQL/** — SQL queries and database analysis
- **PowerBI-Dashboard/** — Power BI dashboard file
- **PNG/** — Dashboard screenshots
- **Project-Overview/PDF/** — Project overview document

## Analysis Highlights
- Crude oil price trend analysis
- Monthly oil price spike identification
- USD/INR exchange rate analysis
- Inflation indicator analysis
- NIFTY 50 and SENSEX trend analysis
- Comparison of economic indicators around oil price spikes

## Dashboard
Dashboard screenshots are available in the `PNG` folder. The Power BI dashboard file is available in `PowerBI-Dashboard`.

## Key Learning Outcomes
- Writing analytical SQL queries using PostgreSQL
- Using CTEs and window functions for time-based analysis
- Comparing trends across multiple economic indicators
- Presenting analytical findings through Power BI

## Disclaimer
This project explores historical data relationships. Observed relationships do not necessarily prove that one economic indicator directly causes changes in another.
